## BingWallE 1.0 – der Bildersammler für Bing-Wallpaper

Das erste Release von BingWallE bietet:

- Galerie mit großer Vorschau, Bildbeschreibung und Copyright.
- Zwölf Regionen und Downloads in HD, Full HD und UHD (soweit von Bing verfügbar).
- Mehrfachauswahl, Erkennung vorhandener Bilder und eigene Dateinamen je Auflösung.
- Fortschritt, Abbruch, Wiederholen und sichere Speicherung über temporäre Dateien.
- Helles/dunkles/Systemdesign und gespeicherte Einstellungen.
- Neues App-Icon und Info-Dialog von Grütze-Software.

### Downloads

| System | Paket |
| --- | --- |
| Windows x64 | `BingWallE-1.0.0-win-x64.zip` – entpacken und `bingwalle.exe` starten |
| Linux x64 | `.deb` für Debian/Ubuntu oder `.tar.gz` zum Entpacken |
| macOS Apple Silicon | `macos-arm64.dmg` oder `.zip` |
| macOS Intel | `macos-x64.dmg` oder `.zip` |

Die .NET-Laufzeit ist enthalten. Linux benötigt eine grafische Desktop-Sitzung
und native Systembibliotheken. Die macOS-Pakete sind ad-hoc signiert, aber nicht
mit einem Apple-Entwicklerzertifikat signiert oder notarisiert; Gatekeeper kann
beim ersten Öffnen eine Freigabe in den Systemeinstellungen verlangen.
Windows-Pakete sind nicht mit einem Code-Signing-Zertifikat signiert.

`SHA256SUMS.txt` enthält die Prüfsummen aller Pakete.
Die Builds und automatisierten Tests laufen über GitHub Actions auf Windows,
Linux und macOS. Die Pakete wurden nicht auf jeder Zielhardware manuell getestet.

BingWallE ist ein unabhängiges Projekt von Grütze-Software.
Bildrechte verbleiben bei den jeweiligen Rechteinhabern; Angaben stehen in der Vorschau.
