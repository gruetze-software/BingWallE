# BingWallE 1.3

- Fit the initial window to the screen work area, accounting for display scaling and window borders.
- Remember normal window size and maximized state on exit, and restore them on the next launch. Previously minimized windows reopen in their last normal/maximized state.
- Add an optional Settings switch to refresh Bing images automatically on startup. It is off by default and does not start downloads.
- Add image context actions: Show, Open Path, Ignore / Stop ignoring, and Delete local.
- Remember ignored images across refreshes and restarts, and skip them in bulk selection and downloads.
- Confirm before permanently deleting a local image. Only the selected resolution is removed; other resolutions are preserved.
- Fit Settings and deletion dialogs to smaller screens. German and English labels are included.

Available for Windows x64, Linux x64 and macOS Intel / Apple Silicon.
