# BingWallE 1.2.1

- Correct the native macOS application menu name to BingWallE.
- Replace the default About Avalonia entry with About BingWallE, opening the application's own information dialog.
- Add Settings (Command+,) and Refresh (Command+R) to the application menu, using the same actions as the main window.
- Menu labels follow the selected German/English interface language. Actions are disabled while busy, in the image preview, or while a modal dialog is open.
- Preserve the standard macOS Services, Hide and Quit actions.

Packages are available for Windows x64, Linux x64 and macOS Intel / Apple Silicon.
