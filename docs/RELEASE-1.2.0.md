# BingWallE 1.2

- The large preview now shows the image description, copyright and useful keywords, with separate attribution for Bing text and optional local AI suggestions.
- Text-derived keywords include supported subjects, broader categories and caption locations. They work without downloading a model. German Bing downloads use German categories; other regions use English categories.
- Optional local recognition also runs in the preview. Suggestions may be incorrect and can differ from full-resolution download results.
- Image comments now contain only the concise description. Publication dates, source links and model scores remain in dedicated XMP fields.
- Existing files remain unchanged until downloaded again.

Packages are available for Windows x64, Linux x64, and macOS Intel / Apple Silicon.
The application displays version **1.2**; package and release version is **1.2.0**.

macOS packages are ad-hoc signed, not Apple-notarized. Follow the macOS instructions in the README if Gatekeeper blocks the first launch.
